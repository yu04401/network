1.1イーサネット規格

規格名は 10GBASE-SR のように 「速度 + BASE + 媒体・符号化記号」 で構成される。 記号の意味を知っていれば、初見の規格名でも媒体と距離感が推測できる。ここは丸暗記より読み方を押さえる。

規格名の読み方

  • 数字＝伝送速度（10 = 10Mbit/s、1000 = 1Gbit/s、10G = 10Gbit/s）
  • BASE＝ベースバンド伝送（信号を変調せずそのまま流す）。対義は BROAD（ブロードバンド）だが現行規格はすべて BASE
  • T＝Twisted pair（より対線＝メタル）
  • S＝Short wavelength（850nm／マルチモード）、L＝Long（1310nm／主にシングルモード）、E＝Extra long（1550nm）
  • X＝8B/10B 符号化、R＝64B/66B 符号化 ← 符号化方式まで規格名に入っている

1.2伝送媒体 ― メタルと光

より対線（ツイストペアケーブル）

UTP（Unshielded Twisted Pair）は、シールドのない撚り対線。LAN配線の標準。 STP（Shielded Twisted Pair）はシールド付きで、工場などノイズの強い環境で使う。 ただしアース（接地）を正しく取らないと逆にノイズを拾うため、施工要件が厳しい。

用語の罠：STP は2つある。 物理層の STP = Shielded Twisted Pair（シールド付きより対線）と、 L2の STP = Spanning Tree Protocol（スパニングツリー）。 午後の問題文では文脈で判別する。答案に書くときは、問題文中の表記をそのまま使うこと。

なぜ「撚る」のか：2本1組で差動信号（＋と−で逆位相）を送るため、外来ノイズは両方の線に同じ向き （コモンモード）で乗る。受信側で差を取るとノイズが相殺される。撚りのピッチを対ごとに変えることで、 対どうしの干渉（クロストーク）も抑えている。

光ファイバ

中心の コアと、その外側の屈折率が低い クラッドの境界で光を全反射させて伝送する。 電磁ノイズの影響を受けず、減衰が小さいため長距離に強い。曲げ・折れに弱く、接続には融着や専用コネクタが要る。

ダークファイバは、通信事業者が敷設済みでまだ使っていない（＝光が通っていない＝暗い）芯線を そのまま借りるサービス。両端の伝送装置は利用者側で用意するため、速度・プロトコルを自由に決められ、 帯域も専有できる。「回線事業者のサービス品目に縛られず大容量を確保したい」という設計要件で登場する。

1.3光トランシーバ（SFP／SFP+／QSFP）

スイッチのポートに後から挿す小型の光モジュール。本体を替えずに、距離・波長・媒体（メタル／光）に応じた モジュールを選べるのが最大の利点。活線挿抜（ホットスワップ）可能。

「同一機種のスイッチだが、拠点Aは 500m、拠点Bは 8km 離れている」→ 本体は共通のまま、SFPだけ SX（MMF）と LX（SMF）で使い分けるという設計の妥当性を書かせる。 「機器を統一でき、保守部品を共通化できる」という運用面のメリットまで書けると強い。

1.4MDI／MDI-X・オートネゴシエーション・二重モード

MDI と MDI-X

MDI（Medium Dependent Interface）は「1・2番ピンで送信、3・6番ピンで受信」する側。 PC・サーバのNIC やルータがこれにあたる。 MDI-Xは機器内部で送受信を入れ替えてある側で、スイッチのポートが該当する（X = Crossover）。

MDI と MDI-X をストレートケーブルでつなげば送信と受信が正しく向き合う。 しかし同じ種類どうし（PC–PC、スイッチ–スイッチ）を結ぶと送信同士がぶつかるため、 かつてはクロスケーブルが必要だった。

オートネゴシエーション

リンクアップ時に FLP（Fast Link Pulse）というパルス列を交換し、 互いが対応する速度と二重モードを通知し合って、両者が使える中で最も高性能な組み合わせを選ぶ仕組み。

相手がオートネゴに応答しない（速度・二重を固定設定している）場合、受信信号の種類から速度だけを推測する パラレル検出にフォールバックする。このとき二重モードは判定できないため、安全側の半二重になる。 これが次の障害を生む。

デュプレックスミスマッチ 頻出

片側が全二重、もう片側が半二重という食い違い。リンクは正常に上がり、pingも通るので気づきにくいが、 半二重側から見ると「相手が送っている最中に自分も送ってくる」状態になり、 コリジョン／レイトコリジョン、FCSエラー、再送が多発してスループットが数%まで落ちる。

設定の組み合わせと結果
機器A機器B結果
AutoAuto正常（両者で全二重を合意）
1000/全二重 固定1000/全二重 固定正常（ただし設定ミスに弱い）
Auto100/全二重 固定ミスマッチ：Aはパラレル検出で100M半二重に。B は全二重 → 障害
■ 午後での問われ方
  • 「リンクは上がっているのに転送速度が極端に遅い」→ 原因は デュプレックスミスマッチ、根拠は片側のみオートネゴ設定
  • 確認方法 →「両端のインタフェースの速度・二重モードの設定値と実際のリンク状態、およびエラーカウンタ（コリジョン／FCSエラー）を確認する」
  • 対策 →「両端をオートネゴシエーションに統一する（またはどちらも同じ値で固定する）」
全二重ならコリジョンは起きない。 送信路と受信路が独立しているため、 CSMA/CD は不要（無効化される）。「コリジョンドメイン」という概念自体が全二重リンクでは意味を持たない。 ここは第2章のリピータハブ／L2スイッチの話につながる。

1.5PoE ― LANケーブルによる給電 頻出

PoE（Power over Ethernet）は、LANケーブルでデータと電力を同時に送る技術。 無線AP・IP電話・ネットワークカメラなど、電源コンセントを引きにくい場所の機器に使う。 給電側を PSE（Power Sourcing Equipment：PoE対応スイッチ等）、 受電側を PD（Powered Device）と呼ぶ。

PSE給電＞PD受電になっているのは、ケーブル上の電力損失（最大100mぶんの導体抵抗）を見込んでいるため。 「給電15.4Wなのに受電12.95W」の差の理由を問われたら、この一言を書く。

給電方式：Alternative A / B

給電開始のシーケンス

  1. 検出（Detection）：PSE が低電圧をかけ、PD 側の 25kΩ の特徴的な抵抗を検出。PoE非対応機器を壊さないための安全確認
  2. クラス分類（Classification）：PD が必要とする電力クラスを判定
  3. 給電開始：規定電圧（44〜57V 程度の直流）を供給
  4. 監視：PD を外すと給電を停止
■ 午後での問われ方
  • 電力バジェット計算：「PoEスイッチの総給電容量 370W。PoE+ の AP（25.5W）を何台収容できるか」といった台数計算。 ポート数ではなくスイッチ全体の給電能力が上限になる点が引っかけ
  • 「APの電源工事が不要になる」＝設置場所の自由度が上がる／工事費を抑えられるという設計上のメリット記述
  • UPS を PoE スイッチにつなげば、AP・IP電話まで一括で無停電化できる（可用性設計との組み合わせ）
  • 802.3af のスイッチに 802.3at の AP をつないだ場合 → 電力不足で起動しない／機能が制限される

1.6ケーブル長制限と伝送遅延

なぜ UTP は 100m なのか

  • 減衰と雑音：距離が伸びるほど信号は減衰し、S/N比が確保できなくなる（現在の主因）
  • スロットタイム：半二重（CSMA/CD）時代は、フレームを送り終える前にコリジョンを検知できる必要があった。 最遠端まで往復する時間（ラウンドトリップ）が最小フレーム送信時間内に収まるよう、ネットワーク直径が制限された

100m の内訳（構造化配線）：フロア配線盤〜情報コンセントの水平配線が最大 90m、 両端のパッチコード等で 10m。合わせて 100m。「機器間で100m」ではなく「配線全体で100m」である点に注意。

1.7符号化

0/1 のビット列をそのまま電圧に置き換えると不都合がある。符号化はそれを解決するための「詰め替え」であり、 目的は次の3つ。

  • クロック同期：受信側がビットの区切りを見失わないよう、信号に定期的な遷移を作る
  • 直流成分の除去（DCバランス）：0または1が続くと直流が偏り、トランス結合された回路を通れない
  • 制御符号・誤り検出：データとして現れない特殊なビット列で、フレームの開始／アイドルなどを表す

4B/5B4ビットを5ビットに変換し、遷移を保証80%100BASE-TX、FDDI

高速になるほどオーバーヘッドを削る方向（20% → 3%）に進化した、という流れで理解する。

1.8多重化 ― TDM と WDM

多重化は、1本の伝送路に複数の通信を同時に載せる技術。何を分割して共有するかで分類する。

TDM（時分割多重）

Time Division Multiplexing。時間を細かいスロットに区切り、 各チャネルに順番に割り当てる。使わなくてもスロットは確保される＝帯域が保証されるのが特徴で、 専用線や SDH／PDH などキャリア網の基盤で使われてきた。逆に空きスロットは無駄になる（統計多重に劣る）。

WDM（波長分割多重）

Wavelength Division Multiplexing。1本の光ファイバに波長の異なる光を同時に流し、 受信側でプリズムのように分離する。ファイバ本数を増やさずに容量を増やせるのが最大の価値で、 敷設コストの高い長距離区間ほど効果が大きい。

多重化方式の整理
方式分割する軸特徴
TDM時間スロット固定。帯域保証。専用線・SDH
FDM周波数アナログ的な分割。放送・ADSLなど
CWDM波長（粗）安価・小規模・中距離。企業の拠点間で採用しやすい
DWDM波長（密）高価・大容量・長距離。キャリアのバックボーン
■ 午後での問われ方

「拠点間のファイバ芯線が2芯しかないが、回線を4系統に増やしたい」→ WDM 装置を導入し、1芯に複数波長を多重する。理由は新規のファイバ敷設が不要で、 短期間・低コストで帯域を増設できるから。ダークファイバ＋WDM はこの文脈でセットで出る。
